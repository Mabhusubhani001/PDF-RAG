# 📄 PDF RAG Frontend (Astro 4 + Tailwind CSS 4)

This directory contains the user-facing web interface for the **PDF RAG Application**, built with **Astro 4**, **Vanilla CSS / Tailwind 4**, and TypeScript.

## 🚀 Development Commands

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build static production bundle
npm run build

# Preview static build
npm run preview
```

## 🌐 Environment Variables

Set `PUBLIC_BACKEND_URL` in `.env` or deployment settings:

```env
PUBLIC_BACKEND_URL=http://localhost:8000
```
